# 決算トレード実運用システム (EarningsTrade-Tracker) 完全運用マニュアル

本システムは、**「東証リアルタイム市場データAPI」** と完全連携し、ダミーや手動推計ではなく、**本物の株価・決算予定日・テクニカル指標・決算後実績値** を自動取得して予測と検証を回す本格トレード支援システムです。

---

## 1. 🚀 クイックスタート

### ワンクリック起動
フォルダ内の **[`起動_決算トレードダッシュボード.bat`](file:///c:/Users/user/Desktop/決算トレード/起動_決算トレードダッシュボード.bat)** をダブルクリックしてください。
自動的にローカルサーバーが立ち上がり、既定のブラウザで **`http://localhost:8080/`** が表示されます。

## 2. 🌟 本物の市場データAPIによる全自動機能

### 🏆 ① 🤖 AI値上がり期待銘柄の「自動発掘・自動ピックアップ」（新機能）
ヘッダーの **「🤖 AI値上がり期待銘柄 自動発掘」** ボタンを1回押すだけで、東証の市場データを高速マルチスレッド走査し、
**「値動きがあり、値が上がる予測のある最有力銘柄」** を全自動でスコアリング・ピックアップします！

#### 【AIスクリーニング＆スコアリングの厳格基準】
1. **決算タイミング**: 決算発表予定日が **約2週間後（7〜35日先）** の絶好の仕込み期
2. **値動き（流動性・ボラティリティ）**: 売買代金・出来高が活発で、十分な値動きの推進力があること
3. **強いテクニカル形状**:
   - `直近高値ブレイク型`（上値抵抗線がなく青天井上昇が期待できる）
   - `25日線押し目反発型`（25日線で綺麗に反発支持され、リスクリワード抜群）
   - `カップウィズハンドル型`（取手形成からの高値上放れ直前）
   - `パーフェクトオーダー`（株価 ≧ 25MA ≧ 75MA の明確な上昇トレンド）
4. **上昇余地とリスクリワード**:
   - 波動計算（N/V/E値）から算出される **想定上昇率が +8%〜+20%以上**
   - 損切り幅に対する期待利益比（**リスクリワード比が 2.0〜3.0倍以上**）
5. **過去勝率フィードバック**: 過去シーズンで勝率の高いパターンに高スコアを付与

👉 画面上に **期待度スコア（Sランク・Aランク）順** に推奨カードが並びます。
- **全選択/個別チェックボックス**: 登録したい銘柄にチェックを入れます（初期状態ですべて選択済み）。
- **「🚀 選択した銘柄を一括登録する」ボタン**: チェックを入れた銘柄を **ワンクリックでまとめて一発登録** できます！
- もちろん、各カードの「この銘柄のみ登録」や「詳細を編集」も利用可能です。

### 📋 監視・予測リストでの操作
- **銘柄コード・銘柄名をクリック**:
  - リスト内の銘柄コード（例: `6501 ↗`）や銘柄名、株価をクリックすると、**自動的に「銘柄ピックアップ＆リアルタイム分析」タブへジャンプ**し、その銘柄の東証リアルタイムデータ・テクニカル指標・波動計算値が一撃で自動展開されます。
- **「📈」ボタン**:
  - 各行のチャートボタンを押すと、高精細な日足ローソク足チャートとAIテクニカル診断モーダルがポップアップします。
- **「📝 結果記録」ボタン**:
  - 決算通過後に実績株価を自動取得して勝敗を確定します。

監視リストの「📈」ボタンや、AI発掘モーダルの「📈 チャートで確認」ボタン、ピックアップフォームの「📈 チャート表示」を押すと、**高精細な日足ローソク足チャートとテクニカル診断パネル** が展開されます：
- **日足ローソク足**: 直近6ヶ月（70営業日）の四本値を鮮やかな陽線（緑）・陰線（赤）で描画。
- **25日・75日移動平均線**: 上昇トレンドやパーフェクトオーダーの並びを可視化。
- **ボリンジャーバンド (±2σ)**: パープルの帯でボラティリティの収縮・拡大（スクイーズとエクスパンション）を一目瞭然に把握。
- **目標株価・損切りライン（点線）**: どこで利確し、どこで撤退すべきかがチャート上にダイレクト表示。
- **出来高バーチャート**: 出来高の急増（大口資金・思惑買いの流入）を視覚的に検知。
- **💡 根拠となるテクニカル診断**:
  - 「【上昇トレンド】株価 ≧ 25MA ≧ 75MA（パーフェクトオーダー形成中）」
  - 「【押し目妙味】25日線乖離率 3.3%（過熱感がなく絶好の買い場）」
  - 「【出来高急増】直近出来高は25日平均の1.66倍」
  - 「【波動計算】安値A・高値B・押し目Cから算出された理論ターゲットN/V/E」
  などを箇条書きで分かりやすく解説！

### ③ ⚡ 決算後1週間の実績株価「一撃自動取得」

決算発表を通過し、約1週間が経過したら、銘柄一覧の「📝 結果記録」ボタンを押してください。
モーダル内の「**⚡ 東証の株価データから決算後1週間の実績値を自動取得**」ボタンを押すと：
- **決算翌日の寄り付き値 (Open)**
- **決算後1週間以内の最高値 (High)**
- **決算後1週間以内の最安値 (Low)**
- **決算後1週間後の終値 (Close)**
が東証の実際の日足から自動入力され、**最大上昇率(%)・確定損益率(%)・目標達成判定・勝敗(WIN/LOSS)** が全自動で判定・記録されます。手作業での株価調べは一切不要です。

## 3. 📊 次期シーズン向け自己学習サイクル

検証済みのトレード結果が蓄積されると、システム内部の分析エンジンが以下のデータを自動更新します：
1. **テクニカルパターン別 勝率ランキング**:
   - 「ブレイクアウト型 vs 押し目反発型 vs カップ型」で、どの形状が最も勝率・平均上昇率が高かったかを自動ランキング。
2. **業績・進捗率帯別のパフォーマンス比較**:
   - どのような業績背景の銘柄が素直に上昇したかを比較。
3. **具体的アドバイスの自動生成**:
   - 「次の四半期決算では、このテクニカル形状を重点的に狙うべき」「この形状は騙しが多かったので警戒」といった実戦的なインサイトを自動生成。
4. **予測時の過去勝率照合**:
   - 新たに候補銘柄を登録する際、過去の同パターンの実績勝率（例: 過去勝率80%）がリアルタイムに照会され、投資判断の精度が高まります。

## 4. 🧹 データベース管理

- **保存先**: `data/earnings_trade.db` （SQLiteデータベース）
- **本番用初期化**: ヘッダー右上の「**🧹 本番用にDB初期化**」ボタンを押すことで、いつでもデータをクリーンな状態にリセットできます。
- **個別削除**: 一覧表のゴミ箱アイコン（🗑️）からいつでも個別レコードを削除できます。
