## 1. 決算シーズンの全体像

### 1.1 年間スケジュール（3月決算企業 = 上場企業の約70%）

| 決算区分 | 対象期間 | 発表時期 | トレード好機度 | 特徴 |
|:---|:---|:---|:---:|:---|
| **1Q（第1四半期）** | 4月〜6月 | 7月下旬〜8月中旬 | ★★★ | 夏枯れ相場で出来高薄い。サプライズ銘柄の反応が大きい |
| **2Q（中間決算）** | 7月〜9月 | 10月下旬〜11月中旬 | ★★★★★ | 通期の折り返し。**上方修正が最も出やすい時期**。決算トレードの最重要シーズン |
| **3Q（第3四半期）** | 10月〜12月 | 1月下旬〜2月中旬 | ★★★★ | 進捗率75%超えで上方修正期待が高まる |
| **本決算（4Q/通期）** | 1月〜3月 | 4月下旬〜5月中旬 | ★★★★ | **翌期ガイダンス**が最大の焦点。配当・自社株買い発表も集中 |

### 1.2 非3月決算企業の活用

3月決算以外の企業を活用することで、年間を通じた決算トレード機会を確保できる。

| 決算月 | 代表的企業/セクター | 決算発表時期 |
|:---|:---|:---|
| **2月決算** | ファーストリテイリング、イオン、セブン&アイ（小売） | 4月/7月/10月/1月 |
| **12月決算** | 信越化学、日産、外資系企業 | 2月/5月/8月/11月 |
| **9月決算** | 一部不動産、サービス業 | 11月/2月/5月/8月 |
| **6月決算** | 任天堂、日本マクドナルド | 8月/11月/2月/5月 |

### 1.3 決算発表の基本ルール

- **発表タイミング**: 大半が引け後（15:00以降）。一部は昼休み（11:30〜12:30）
- **開示ルール**: 決算期末から45日以内の開示が東証から要請されている
- **集中日**: ピーク日には1日300社以上が発表。集中日は翌日の値動きが激しくなる
- **確認方法**: TDnet（適時開示情報）、株探の決算カレンダー

## 2. 決算前の値動きパターン

### 2.1 決算前ドリフト（Pre-Earnings Drift）

好決算が期待される銘柄は、発表の**1〜3週間前**から徐々に上昇する傾向がある。これを「先回り買い」「決算プレー」と呼ぶ。

#### なぜ発生するか

1. **インサイダー的な情報の漏洩**: 取引先や従業員からの間接的な情報が市場に流れる
2. **アナリストの事前予想修正**: カバレッジアナリストが予想を上方修正すると買いが入る
3. **過去パターンの学習**: 機関投資家が「この企業は毎年この時期に上方修正する」と学習
4. **需給要因**: 配当権利取りの買い、インデックスファンドのリバランス

### 2.2 決算前に上がりやすい銘柄の特徴

| # | 要素 | 具体的条件 | 確認方法 |
|:---|:---|:---|:---|
| 1 | **進捗率** | 1Qで30%超、2Qで55%超、3Qで80%超 | 銘柄スカウター、株探 |
| 2 | **修正パターン** | 過去3年以上、同四半期で上方修正の実績 | 四季報、IR資料 |
| 3 | **四季報 > 会社予想** | 四季報独自予想が会社計画を上回る | 四季報オンライン |
| 4 | **アナリスト少ない** | カバレッジ0〜3名 | Bloomberg、各社HP |
| 5 | **株価位置** | 25日移動平均線の上、52週高値から-20%以下 | チャート |
| 6 | **信用倍率** | 1.0倍以下（売り長） | 信用残データ |
| 7 | **セクターの追い風** | 業界全体の受注・出荷が好調 | 業界紙、統計データ |

### 2.3 決算前に下がりやすい銘柄の特徴

| # | 要素 | 具体的条件 |
|:---|:---|:---|
| 1 | **進捗率低迷** | 1Qで20%未満、2Qで45%未満 |
| 2 | **株価先行上昇** | 52週高値圏、「期待の先食い」状態 |
| 3 | **信用買い残急増** | 直近1ヶ月で信用買い残が50%以上増加 |
| 4 | **業界逆風** | 為替（円高で輸出不利）、規制強化 |
| 5 | **会社予想が慎重** | 経営者が保守的なコメントを出している |

## 3. 決算後の値動きパターン

### 3.1 決算後ドリフト（PEAD: Post-Earnings Announcement Drift）

**アカデミック研究で最も確実に確認されているアノマリー**。
ポジティブサプライズ銘柄は発表後も**数週間〜数ヶ月**にわたって同方向に動き続ける。

#### PEAD の根拠

- **投資家の限定的合理性**: 新情報をすぐに完全には織り込めない
- **アンカリング効果**: 投資家は古い予想に固執し、新情報への修正が遅れる
- **小型株効果**: 機関投資家のカバレッジが少ない銘柄ほど効果が強い
- **日本市場での実証**: 複数のアカデミック論文で日本市場でのPEAD存在が確認済み

#### PEAD が強く出る条件

| 要素 | 条件 | 理由 |
|:---|:---|:---|
| **時価総額** | 100億〜2,000億円 | 情報伝達が遅い |
| **個人投資家比率** | 高い | 情報処理能力に限界 |
| **アナリストカバレッジ** | 少ない（0〜3名） | プロの目が届きにくい |
| **サプライズ幅** | コンセンサス比+15%以上 | 大きいほどドリフトが長期化 |
| **流動性** | やや低い（売買代金1〜10億円/日） | 一気に織り込まれない |

### 3.2 決算後に急騰する5パターン

#### パターン1: 上方修正 + 増配のダブルサプライズ

- **反応**: ストップ高〜翌日もギャップアップ
- **持続性**: 2〜4週間上昇トレンドが続く
- **確認**: 営業利益上方修正幅+配当増額を同時チェック

#### パターン2: 黒字転換（ターンアラウンド）

- **反応**: 市場評価が一変し、PER再評価で急騰
- **持続性**: 1〜3ヶ月の大型トレンド
- **注意**: 一過性の黒字（特別利益）か本業黒字かを見極め

#### パターン3: 自社株買い発表

- **反応**: EPS向上→PER低下→割安感
- **持続性**: 実施期間中は需給が支え
- **確認**: 取得株数上限、取得金額上限、実施期間

#### パターン4: テーマ株 × 好決算

- **反応**: テーマの期待 + 数字の裏付けで暴騰
- **持続性**: テーマの旬が続く限り持続
- **例**: AI関連銘柄がAI事業の売上急増を発表

#### パターン5: 空売り踏み上げ

- **条件**: 信用倍率1倍未満 × 好決算
- **反応**: 空売り勢の買い戻しが連鎖→急騰
- **特徴**: 短期的に非常に強い上昇（1〜3日）

### 3.3 「好決算なのに下がる」パターン

| パターン | 説明 | 見分け方 |
|:---|:---|:---|
| **材料出尽くし** | 株価が先行して大幅上昇済み | 決算前1ヶ月の騰落率が+20%以上 |
| **来期ガイダンスが弱い** | 今期好調でも来期予想が保守的 | 来期営業利益予想が今期比横ばい以下 |
| **コンセンサス未達** | 絶対値は良いが「期待」に未達 | アナリスト予想の中央値との比較 |
| **一過性利益** | 資産売却等の特別利益 | 営業利益vs純利益の乖離 |
| **ガイダンス非開示** | 不確実性を嫌気して売り | 「合理的な算定が困難」等の文言 |

## 4. コンセンサスと実績の分析

### 4.1 分析すべき指標と優先度

| 優先度 | 指標 | 内容 | 株価へのインパクト |
|:---:|:---|:---|:---:|
| ★★★★★ | **営業利益** | 本業の収益力 | 最大 |
| ★★★★ | **売上高** | トップラインの成長 | 大 |
| ★★★★ | **来期ガイダンス** | 経営陣の将来見通し | 大（本決算時は最大） |
| ★★★ | **純利益/EPS** | 最終利益（PERの基礎） | 中〜大 |
| ★★★ | **経常利益** | 為替差益を含む | 中（輸出企業で重要） |
| ★★ | **配当** | 株主還元（増配/減配） | 中 |
| ★★ | **自社株買い** | 需給と資本効率 | 中 |
| ★ | **ROE** | 自己資本利益率 | 小（中長期で重要） |

### 4.2 サプライズ度の計算

```
サプライズ度(%) = (実績値 − コンセンサス予想) ÷ |コンセンサス予想| × 100
```

| サプライズ度 | 市場の反応 | トレードアクション |
|:---|:---|:---|
| +30%以上 | ストップ高級のインパクト | PEAD戦略で即エントリー |
| +15〜30% | 強い上昇（+5〜15%） | PEAD戦略の対象 |
| +5〜15% | 穏やかな上昇（+2〜5%） | 他条件次第でエントリー検討 |
| -5〜+5% | ほぼ予想通り、反応小 | スルー |
| -5〜-15% | 穏やかな下落 | 空売り検討 |
| -15%以下 | 急落・ストップ安リスク | 保有中なら即損切り |

### 4.3 会社予想 vs コンセンサス vs 四季報予想

日本市場特有のポイントとして、**3つの予想**が存在する。

```
┌─────────────────────────────────────────────────┐
│  会社予想（最も保守的）                           │
│    ↓ 通常はここが最も低い                        │
│  コンセンサス予想（アナリスト平均）               │
│    ↓ 保守性を織り込んで上方修正                  │
│  四季報予想（独自取材ベース）                     │
│    ↓ さらに楽観的な場合あり                      │
└─────────────────────────────────────────────────┘
```

**戦略上の活用法**:
- 会社予想 < コンセンサス ≒ 四季報 → 上方修正の「サプライズ度」は小さい（織り込み済み）
- 会社予想 ≒ コンセンサス < 四季報 → 四季報がより強気 → 上方修正余地あり
- 会社予想 ≒ コンセンサス ≒ 四季報 → サプライズの余地が大きい or 小さい（要分析）

## 5. 進捗率分析

### 5.1 基本的な進捗率の目安

```
進捗率(%) = 累計実績（営業利益） ÷ 通期会社予想 × 100
```

| 四半期 | 標準進捗率 | 上方修正期待ライン | 強い上方修正シグナル |
|:---|:---:|:---:|:---:|
| 1Q | 25% | 30%以上 | 35%以上 |
| 2Q（中間） | 50% | 55%以上 | 60%以上 |
| 3Q | 75% | 80%以上 | 85%以上 |

### 5.2 季節性を考慮した進捗率分析（重要）

**単純な25%刻みでは不十分**。業種ごとに利益の季節偏差がある。

| 業種 | 利益偏重期 | 典型的な1Q進捗率 | 注意点 |
|:---|:---|:---:|:---|
| **飲料メーカー** | 夏（1Q） | 35〜40% | 1Qが高くても季節要因 |
| **小売業** | 年末商戦（3Q） | 15〜20% | 1Qが低くても正常 |
| **建設業** | 年度末（4Q） | 10〜15% | 4Qに利益集中 |
| **エアコンメーカー** | 夏（1Q） | 30〜35% | 1Qが高いのは通常 |
| **IT/ソフトウェア** | 比較的均等 | 23〜27% | 標準の目安が使いやすい |

#### 正しい分析手順

```
1. 過去5年分の同四半期の進捗率を収集
2. 5年平均進捗率を算出
3. 今期の進捗率と5年平均を比較
4. 乖離が+5ポイント以上 → 上方修正の可能性高い
```

### 5.3 進捗率と株価反応の関係

| 進捗率の状況 | 上方修正確率 | 株価への影響 |
|:---|:---:|:---|
| 5年平均を10pt以上上回る | 80%以上 | 発表前から先回り買い。発表後も上昇 |
| 5年平均を5-10pt上回る | 50-70% | 発表前はやや上昇。発表後は内容次第 |
| 5年平均とほぼ同じ | 10-30% | 通常は予想通り。サプライズ小 |
| 5年平均を下回る | 5%未満 | 下方修正リスク。注意 |

## 6. 配当・株主還元の分析

### 6.1 増配のインパクト

| 増配パターン | 株価反応 | 持続性 |
|:---|:---|:---|
| **連続増配の継続** | 穏やか（織り込み済み） | 長期的にプラス |
| **増配率の加速**（例: 前年+5円→今年+15円） | 強い反応 | 中期的にプラス |
| **配当性向の引き上げ宣言** | 非常に強い反応 | 長期的にプラス |
| **特別配当** | 一時的に強い反応 | 短期のみ |
| **減配** | 強い下落 | 長期的にマイナス |

### 6.2 自社株買いのインパクト

```
自社株買いインパクト = 取得金額 ÷ 時価総額 × 100
```

| 取得規模（対時価総額） | 株価反応 |
|:---|:---|
| 5%以上 | 非常に強い（需給が大きく改善） |
| 2〜5% | 強い |
| 1〜2% | 中程度 |
| 1%未満 | 限定的 |

### 6.3 総還元性向の分析

```
総還元性向(%) = (配当金 + 自社株買い) ÷ 純利益 × 100
```

- 東証の「資本コストを意識した経営」要請により、PBR1倍割れ企業の還元強化が進行中
- 総還元性向50%以上を掲げる企業は、継続的な株価上昇が期待できる

## 7. 戦略A: 決算前モメンタム

### 7.1 概要

| 項目 | 内容 |
|:---|:---|
| **期間** | 決算発表の10〜15営業日前〜発表前日 |
| **目標リターン** | +15〜20%（レバレッジ2倍で+30〜50%） |
| **リスク** | 中（決算前に手仕舞うため、決算リスクなし） |
| **適切な資金配分** | 総資金の40〜50% |

### 7.2 銘柄スクリーニング条件

以下の条件を**全て満たす**銘柄をウォッチリストに登録:

```
□ 時価総額: 100億円〜2,000億円
□ 進捗率: 過去5年平均を5ポイント以上上回る
□ 四季報予想 > 会社予想
□ 株価位置: 25日移動平均線の上
□ 株価位置: 52週高値から-10%以上下
□ 出来高: 平均売買代金 1億円以上
□ 信用倍率: 3倍以下
□ PER: セクター平均以下
□ 直近の業界動向: ポジティブ（受注増、需要増等）
```

### 7.3 エントリールール

1. **タイミング**: 決算発表の10〜15営業日前
2. **分割買い**: 3回に分けてエントリー（初回40%、2回目30%、3回目30%）
3. **1銘柄あたり**: 総資金の10%以内（信用含む）
4. **同時保有**: 最大5銘柄

### 7.4 エグジットルール

| 条件 | アクション |
|:---|:---|
| +15%到達 | 半分利確 |
| +20%到達 | さらに半分利確 |
| 決算発表前日の大引け | 残り全て手仕舞い |
| -5%到達 | 全額損切り（例外なし） |
| 出来高が急減 | モメンタム喪失、手仕舞い検討 |

### 7.5 期待値計算

```
5銘柄に分散投資の場合（レバレッジ2倍）:

勝ち: 3銘柄 × +15% × 2倍 = +90%分の資金増
負け: 2銘柄 × -5% × 2倍 = -20%分の資金減
差引: +70%分 ÷ 5銘柄 = 平均+14%/銘柄

ポートフォリオ全体: 約+28%〜+40%
```

## 8. 戦略B: 決算またぎ

### 8.1 概要

| 項目 | 内容 |
|:---|:---|
| **期間** | 決算発表当日〜発表翌営業日（最短1日） |
| **目標リターン** | +20〜30%（ギャップアップ狙い） |
| **リスク** | 高（ギャップダウンの可能性あり） |
| **適切な資金配分** | 総資金の20〜30% |

### 8.2 ハイコンビクション条件（全て満たす銘柄のみ）

```
□ 進捗率: 過去5年平均を10ポイント以上上回る
□ 直近四半期: 前年同期比+20%以上の営業利益成長
□ 信用倍率: 1.5倍以下（理想は1倍未満 = 売り長）
□ コンセンサス ≒ 会社予想（上方修正が織り込まれていない）
□ 直近1ヶ月の株価上昇率: +10%以内（過度な期待なし）
□ 時価総額: 100億〜2,000億円
□ テーマ性: 旬のテーマに関連（AI、半導体、防衛等）
□ チャート: 25日・75日移動平均線の上
```

### 8.3 エントリールール

1. **タイミング**: 決算発表当日の前場〜大引け
2. **ポジションサイズ**: 1銘柄あたり総資金の10〜15%（信用含む）
3. **同時保有**: 最大2〜3銘柄
4. **逆指値**: ギャップダウンに備え、翌日の逆指値注文を事前設定

### 8.4 エグジットルール

| 翌日のギャップ | アクション |
|:---|:---|
| **+15%以上のギャップアップ** | 寄付きで50%利確、残りは当日中に判断 |
| **+5〜15%のギャップアップ** | ホールド。+20%で半分利確 |
| **0〜+5%** | 当日の動き次第。引けまでにほぼ全額利確 |
| **ギャップダウン** | **寄付きで全額損切り（例外なし）** |

### 8.5 絶対禁止事項

- ❌ 「確信がない」のに決算またぎをしない
- ❌ ギャップダウンでナンピンしない
- ❌ SNSの煽りだけで銘柄を選ばない
- ❌ 1銘柄に全資金を投入しない
- ❌ 損切り注文を外さない

## 9. 戦略C: 決算後ドリフト（PEAD）

### 9.1 概要

| 項目 | 内容 |
|:---|:---|
| **期間** | 決算発表翌日〜2〜4週間 |
| **目標リターン** | +15〜25%（トレンドフォロー） |
| **リスク** | 中低（事実確認後のエントリー） |
| **適切な資金配分** | 総資金の30〜40% |

### 9.2 銘柄スクリーニング条件（決算発表後に実施）

```
□ サプライズ度: コンセンサス比+15%以上の営業利益上振れ
□ 上方修正発表あり（会社予想を引き上げ）
□ 増配 or 自社株買い（あればボーナスファクター）
□ 時価総額: 100億〜2,000億円
□ 発表翌日の出来高: 直近20日平均の3倍以上
□ 来期ガイダンス: ポジティブ or 据え置き
□ 決算発表翌日に陽線（終値 > 始値）
```

### 9.3 エントリールール

1. **タイミング**: 決算発表の翌営業日〜3営業日目
2. **確認事項**: 初動のギャップアップ後、さらに高値を更新しているか
3. **分割買い**: 2回に分けてエントリー（初回60%、押し目で残り40%）
4. **ポジションサイズ**: 1銘柄あたり総資金の10〜15%
5. **同時保有**: 最大4銘柄

### 9.4 エグジットルール

| 条件 | アクション |
|:---|:---|
| +20%到達 | 半分利確（トレーリングストップに移行） |
| +30%到達 | さらに半分利確 |
| 25日移動平均線を下回って引ける | 全額手仕舞い |
| -7%到達 | 全額損切り |
| エントリーから4週間経過 | 利益が出ていても全ポジション解消 |

### 9.5 この戦略の強み

- **「事実」を確認後のエントリー**なので不確実性が低い
- **PEAD（アカデミックに実証されたアノマリー）**を活用
- **小型株で効果が大きい**ため、100万円規模の資金に最適
- **勝率が他の戦略より高い**（55〜60%程度）

## 10. リスク管理ルール

### 10.1 ポジションサイジングの鉄則

```
許容損失額 = 総資金 × 2%
ポジションサイズ = 許容損失額 ÷ 損切り幅

【例】
総資金: 100万円
許容損失額: 100万円 × 2% = 2万円
損切り幅: 5%（エントリー価格の5%下で損切り）
ポジションサイズ: 2万円 ÷ 5% = 40万円
→ この銘柄は最大40万円まで投入可能
```

### 10.2 損切りルール一覧

| 状況 | 損切りライン | 備考 |
|:---|:---|:---|
| 戦略A（決算前モメンタム） | -5% | 決算前に手仕舞い |
| 戦略B（決算またぎ） | ギャップダウン即切り | 翌日寄付きで全額 |
| 戦略C（PEAD） | -7% | トレンド否定 |
| 全体ドローダウン | -15% | 全ポジション解消・戦略再評価 |
| 連敗 | 3連敗 | 2日間の取引休止 |

### 10.3 レバレッジ管理

| ルール | 内容 |
|:---|:---|
| **最大レバレッジ** | 自己資金の2.5倍まで |
| **決算またぎ時** | 自己資金の2倍まで |
| **ドローダウン中** | レバレッジ1倍（現物のみ） |
| **勝ちが続いている時** | 段階的に引き上げ可（最大2.5倍） |

### 10.4 メンタル管理

1. **トレード前**: エントリー理由、利確・損切りラインを紙に書く
2. **トレード中**: 設定した損切りラインを絶対に変えない
3. **トレード後**: 日誌に結果と感情を記録
4. **大負けの後**: 最低2日間は取引しない
5. **大勝ちの後**: ポジションサイズを増やさない（翌日は通常量）
